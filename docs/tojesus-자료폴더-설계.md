# tojesus 자료 폴더 — 설계 (확정)

- 2026-10-18 초안 · 같은 날 대표 수정·확정 반영 → **1단계 v5.26.0 으로 만듦**
- 형제 앱 「함께 예수께로」와의 약속: `Gospel_Harmony/EGW/tojesus-데이터셋-설계.md` **덧붙임 4** (예전 7항을 대신한다)

---

## 0. 한눈에

- 휴대폰·태블릿의 **내장 저장소 맨 위 또는 SD카드 맨 위**에 `tojesus/` 폴더를 하나 두고, 앱이 **한 번만 연결**(읽기·쓰기)한다.
- 그 아래를 **구역 여덟**으로 나눈다 — 아래 2항.
- **압축파일 넣기** — 압축을 고르면 앱이 목차만 읽어 구역마다 행선지를 보여 준 뒤, **안드로이드가 흘려 풀어** 넣는다(640MB 를 메모리에 올리지 않는다). 다 풀면 **원본을 지울지 묻는다**.
- **🔄 재등록** — 첫화면 ⚙ 설정 › 파일관리의 단추 하나로, 연결 확인 → 빠진 구역 폴더 만들기 → 훑기 → 구역마다 들이기·연결을 **알아서** 한다.
- 다른 화면의 입구(성경 DB 관리 · 매일찬양 설정)에는 **이 화면으로 가는 지름길**을 둔다.

## 1. 확정 사항 (대표 결정 2026-10-18)

| 항목 | 결정 |
|---|---|
| 폴더 자리 | 공용 폴더(내장·SD카드 맨 위) + 한 번 연결. 안드로이드의 앱 전용 폴더(`Android/data`)는 앱을 지우면 사라지므로 쓰지 않는다 |
| 폴더 이름 | 영어 소문자. 오디오는 원본 자료와 **분리** — `audiobible` · `audioegw` · `audiosermon` |
| 찬미가 가사·악보 `.hdb` `.cmp` | **`bethlehem/` 그대로** — 베들레헴 성경 자료다 |
| 찬양 음원(`praise`) | **앱 안에 복사** — 매일찬양의 담기 화면(분류·채널·태그 확인)을 그대로 쓴다 |
| 형제 앱 약속 | **새 이름으로 고친다. 옛 이름(`Bethlehem`·`EGW`·`Hymns`·`Music`·`aBook`)을 따로 기억하지 않는다** |
| 다 푼 압축 원본 | **지울지 물어본다** |

옛 이름 별칭은 두지 않았지만, 옛 모양의 압축(`Bethlehem/…`·`EGW/…`·`Hymns/연합회/반주/…`)도 **파일 속과 대소문자 무시**로
제자리를 찾는다(3항 규칙). 폴더 이름을 외우지 않아도 되는 까닭이다.

## 2. 폴더 배치

```
tojesus/                         ← 내장 저장소 맨 위 또는 SD카드 맨 위
├─ tojesus.json                  폴더 표지(앱이 만든다) — 구역 목록·만든 앱·날짜
│
├─ bethlehem/                    베들레헴 성경 자료                  → 앱 안으로 복사
│     .bdb 역본 · .cdb 주석 · .sdb 원어 · .dct 사전 · .hdb 찬미가 가사 · .cmp 찬미가 악보
│
├─ audiobible/                   성경 오디오(베들레헴 자료가 아니라 따로)  → 자리만 기억
│  └─ 개역한글/01_창세기/001.mp3   <역본>/<책번호2자리_책이름>/<장3자리>
│
├─ egwbooks/                     화잇 저서 .wdb                       → 앱 안으로 복사
│
├─ audioegw/                     예언의신 오디오                       → 자리만 기억
│  └─ KR/시대의소망/001.mp3        <언어>/<책>/<장3자리>
│                                 언어: KR 한국어 · EN 영어 · CN 중국어 · JP 일본어 · ID 인도네시아어
│
├─ sdahymnal/                    찬미가(연합회 미디 반주)
│  ├─ 주소록.json                 인터넷 음원 주소록                    → 앱 안으로
│  ├─ 연합회/반주/001.mp3          <출처>/반주·찬양/<장3자리>             → 찬미가 음원 폴더로 연결
│  └─ 연합회/찬양/001.mp3          (출처 칸 없이 반주/·찬양/ 만 두어도 된다)
│
├─ praise/                       그 밖의 찬양                          → 매일찬양에 복사
│  └─ 손영진 베스트/…mp3           <앨범> — 앨범 이름이 분류·태그가 된다
│
├─ audiosermon/                  설교 · 오디오북                       → 자리만 기억
│  ├─ 설교자이름/2026-10-18_제목.mp3
│  └─ 책이름/001.mp3
│
└─ _inbox/                       받은 압축파일 — PC·USB 로 넣어 두면 재등록 때 풀지 묻는다
```

**다룸 넷**

| 다룸 | 구역 | 까닭 |
|---|---|---|
| **앱 안으로 복사** | bethlehem · egwbooks · 주소록 | 작고, 읽을 때마다 폴더를 뒤지면 느리다. **날짜를 먼저 견주어 새것만** 읽는다 |
| **찬미가 음원 폴더로 연결** | sdahymnal 의 음원 | 7GB 넘을 수 있다 — 복사하지 않는다. 매일찬양 설정에서 따로 고를 일이 없어진다 |
| **매일찬양에 복사** | praise | 매일찬양 서재·알람이 앱 안의 음원을 쓴다(결정). 담은 곡은 경로로 기억해 다음 재등록에서 「새 곡」만 센다 |
| **자리만 기억** | audiobible · audioegw · audiosermon | 세어서 보여 준다. **재생 화면은 아직 없다**(3단계) |

**이름 규칙** — 숫자는 자릿수를 맞춘다(`001` · `01_`). 파일 관리자·PC 에서도 같은 순서로 보이게.

## 3. 압축파일 넣기

```
[🗜 압축파일 넣기] ─ 압축 고르기(여럿 가능) 또는 재등록 때 _inbox/ 에서 찾은 것
   ├─ ① 목차만 읽는다 — 안드로이드가 압축 끝의 목차(central directory)만. 몇 초
   ├─ ② 행선지를 정한다 — 아래 규칙
   ├─ ③ 미리보기 — 구역마다 개수·크기. 어디인지 모르는 음원은 구역을 고른다(기본 찬양 앨범)
   ├─ ④ 푼다 — 안드로이드가 한 파일씩 흘려 읽어 그 폴더에 바로 쓴다. 진행 막대 · 그만두기
   │         같은 크기의 파일이 이미 있으면 건너뛴다(다시 넣어도 빠르다). 그만두면 반쯤 쓴 파일은 지운다
   ├─ ⑤ 원본 압축을 지울지 묻는다(못 푼 파일이 있으면 남겨 두기를 권한다)
   └─ ⑥ 이어서 재등록
```

### 행선지 규칙 (`js/dataset-import.js` placeEntry) — 위에서부터 먼저 맞는 것

0. 맥 찌꺼기(`__MACOSX/`·`._이름`·`.DS_Store`)는 버린다. 압축 전체가 **폴더 하나에 싸여 있으면**(맥 파인더 압축) 그 껍질을 뗀다
   — 단 그 껍질이 구역 이름이나 `tojesus` 면 그대로
1. 경로가 `tojesus/` 로 시작하면 떼고 본다
2. 맨 위가 **구역 이름**(대소문자 무시)이면 그 자리 그대로. `audioegw/kr/` → `audioegw/KR/`
3. 확장자: `.bdb .cdb .sdb .dct .hdb .cmp` → `bethlehem/` · `.wdb` → `egwbooks/` · `.json` → `sdahymnal/` · `.zip` → `_inbox/`
4. 음원이 `반주/`·`찬양/` 칸 안의 `001…` 이름 → `sdahymnal/<출처>/반주|찬양/` (바로 위 칸이 `Hymns` 같은 그릇이면 출처 없음)
5. 그 밖의 음원 → **미리보기에서 고른다**. 폴더 없이 들어 있던 곡은 압축 이름으로 한 칸을 만들어 묶는다
6. 그 밖의 파일(문서·그림)은 풀지 않는다

압축 안 한글 이름: 「UTF-8」 표시가 있으면 UTF-8, 없으면 UTF-8 로 풀어 보고(맥 파인더) 안 되면 윈도우 한글(MS949), 자모는 다시 붙인다(NFC).

## 4. 🔄 재등록

```
[🔄 재등록]
 ① 연결 확인 — 처음이거나 앱을 다시 깔았으면 고르는 창(저장소 맨 위에서 열린다)
      tojesus 를 고르면 그대로 · 그 위 폴더를 고르면 안에서 찾거나 만든다
      SD카드가 빠졌거나 권한이 거둬졌으면 알리고 다시 고르게 한다
 ② 빠진 구역 폴더를 만든다 · tojesus.json 을 쓴다
 ③ 훑는다 — 이름·크기·날짜만
 ④ 구역마다 (2항 표) · 구역 폴더 밖의 파일은 읽지 않고 알린다
 ⑤ 결과 — 한 줄 요약 + 구역별 개수. 못 들인 자료·폴더 밖 파일은 목록으로 알린다
 ⑥ _inbox 에 압축이 있으면 풀지 묻는다 · 찬양 새 곡이 있으면 매일찬양에서 담을지 묻는다
```

몇 번을 눌러도 탈이 없다 — 자료는 새것만, 찬양은 아직 안 담은 곡만, 압축은 같은 크기면 건너뛴다.

## 7. 시험한 것 (에뮬레이터, 안드로이드 16 태블릿)

- 연결: 고르는 창이 저장소 맨 위에서 열림 → tojesus 고름 → 구역 폴더 8개·표지 생김. 다시 켠 뒤에도 연결·쓰기 권한 유지
- 맥 파인더(ditto)로 만든 압축(UTF-8 표시 없음·`__MACOSX` 찌꺼기·껍질 폴더): 한글 이름 그대로, 6개 모두 제자리, md5 원본과 같음, 원본 지우기 됨
- 168MB 압축(풀면 309MB, 베들레헴 15개): 10초 안에 풂, 앱 메모리 259MB 그대로(치솟지 않음), 115MB 악보 md5 같음
- 재등록: 자료 14개 새로 17.5초(메모리 그대로) · 다시 누르면 읽지 않고 건너뜀 · 주소록 1 · 찬미가 음원 폴더 자동 연결(반주 재생 파일 크기 원본과 같음)
- 찬양: 새 곡 3 → 매일찬양 담기 화면 → 3곡·음원 3 · 다시 재등록하면 새 곡 0
- _inbox 압축: 경로로 풀기(같은 크기 6개 건너뜀) · 원본 지우기 · 「취소」면 남김

### 코드 검토 뒤 고친 것

- 원본 지우기 안내 — 풀지 않은 파일(문서·그림·「풀지 않음」으로 둔 음원)이 있으면 개수를 알리고 남겨 두기를 권한다
- 풀어 쓴 크기가 목차와 다르면(잘린 압축) 실패로 세고 그 파일을 지운다 · 목차 개수가 맞지 않으면(깨진 압축) 처음부터 멈춘다
- 풀다가 실패하면 반쯤 쓴 파일을 지운다(다음 재등록이 깨진 자료를 읽지 않게)
- `? : * " < > |` 가 든 이름은 미리 `_` 로 — 제공자가 몰래 바꿔 다음에 「이름 (1)」 사본이 늘던 구멍
- 받은 압축을 풀고 이어 재등록할 때 남겨 둔 그 압축을 또 묻지 않는다
- 사람이 직접 고른 찬미가 폴더가 있으면 tojesus/sdahymnal 로 바꿀지 묻는다 · 연결을 옮기면 옛 자리의 찬미가 칸은 놓는다
- 찬양 「담은 곡」 표시는 담은 뒤에만, 곡마다 저장 · 구름 폴더는 고를 때 거른다 · 다른 자리로 옮기면 옛 권한을 놓는다
- 시험: 금지 글자 이름 → `왜_노래_1.mp3`, 다시 풀면 「이미 있음 1」(사본 없음) · 잘린 압축은 「받다 끊겼거나…」로 거부

**한 번 본 이상한 일** — 첫 찬양 담기 직후 음원 저장소가 비어 있었다(곡 정보는 남음 · 앱은 다시 켜지지 않았음).
같은 길을 두 번(저장소를 지운 처음 상태 포함) 다시 했을 때는 모두 제대로 담겼고, 에뮬레이터를 다시 켠 뒤에도 남았다.
그때 맥이 메모리 부족(여유 183MB)이고 에뮬레이터가 「응답 없음」을 거듭 띄우던 중이었다 — 실기기에서 한 번 더 본다.

**못 본 것** — 실제 태블릿 · SD카드 · 640MB 전체 압축 · 구름 폴더에서 고른 압축(풀 수 없다고 알리게 했다)
