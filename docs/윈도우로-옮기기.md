# 윈도우로 옮기기 — 「항상 예수께로」 작업을 윈도우 데스크톱의 Claude Code 에서 잇는다

2026-10-08 맥에서 묶음. 묶음 파일은 구글드라이브(imotungi) `내 드라이브/항상예수께로_윈도우이전/` 에 있다.
이 문서는 저장소에도 들어 있으니, 묶음을 풀기 전에도 GitHub 에서 읽을 수 있다.

빌드가 만드는 것(`www/` · `node_modules/` · `android/app/build/` · `산출물APK/`)은 옮기지 않는다 — 윈도우에서 다시 만든다.
최신 APK(5.23.1)는 드라이브 `내 드라이브` 맨 위에 있다.

## 1. 윈도우에 깔 것

1. **Git for Windows** — Git Bash 가 함께 깔린다(빌드 스크립트는 bash 로 돈다)
2. **Node.js LTS**(20 이상) — Capacitor 8
3. **Android Studio** — 처음 켜서 SDK Platform 36 · Build-Tools 36 을 받는다(JDK 는 Android Studio 에 들어 있다)
4. **Python 3** — 파이선 스크립트(`scripts/*.py`)는 표준 라이브러리만 쓴다. `pip install` 할 것 없음
5. **GitHub CLI(gh)** — 개인 저장소에 푸시할 때
6. **Claude Code**(데스크톱 앱) · **Google Drive for desktop**(묶음 받기)

## 2. 폴더 자리 — ⚠ 영문 경로

안드로이드 빌드 도구는 윈도우에서 **경로에 한글이 있으면 빌드를 막는다**. 맥에서는 `~/claude_code/Jonathan_CD/성경절암송` 이었지만
윈도우에서는 영문으로 둔다. 윈도우 사용자 이름이 한글이면 `C:\Users\…` 도 피한다.

```
C:\dev\claude_code\                 ← 맥의 ~/claude_code 자리
  CLAUDE.md                         ← 3_맥락/CLAUDE.md (상위 지침 — 아래 폴더들을 가리킨다)
  airekka-design-system\            ← 3_맥락/airekka-design-system (작업 방식 working-style 포함)
  _디자인\디자인\                     ← 3_맥락/_디자인/디자인 (디자인 기억 정본 · CSS)
  biblemem\                         ← 이 저장소(맥의 성경절암송)
C:\dev\keys\biblemem-release.jks    ← 6_서명키
```

`3_맥락/CLAUDE.md` 안의 경로는 맥 경로(`~/claude_code/…`)다 — 윈도우 Claude Code 에게 위 자리로 고쳐 달라고 하면 된다.
(디자인 폴더 `_디자인` 은 빌드와 상관없어 한글이어도 괜찮다)

## 3. 코드 받기

GitHub 로 받기(권장 — 앞으로 푸시도 이 길):
```
gh auth login            # Jonathan-Jyo 계정으로
cd C:\dev\claude_code
gh repo clone Jonathan-Jyo/mbible biblemem
```
GitHub 없이 받기: `git clone 1_코드\mbible.bundle biblemem` 뒤 `git remote set-url origin https://github.com/Jonathan-Jyo/mbible.git`

그다음:
```
cd biblemem
npm install              # patches/ 의 음성 인식 플러그인 고침도 함께 입혀진다(patch-package)
```

## 5. 서명 키 (`6_서명키/`) ⚠

- `biblemem-release.jks` 를 `C:\dev\keys\` 에, `keystore.properties` 를 `biblemem\android\` 에 둔다
- `keystore.properties` 의 `storeFile=` 을 윈도우 경로로 고친다: `storeFile=C:/dev/keys/biblemem-release.jks` (슬래시 `/`)
- 이 키가 있어야 윈도우에서 빌드한 APK 를 지금 깔린 앱 위에 덮어 깔 수 있다(서명이 다르면 지우고 새로 깔아야 하고 기록이 사라진다)
- 키·비밀번호는 깃에 넣지 않는다(`.gitignore` 처리됨). 다 옮겼으면 드라이브의 `6_서명키` 는 지우는 것이 안전하다

## 6. 빌드 (Git Bash 에서)

```
export ANDROID_HOME="$LOCALAPPDATA/Android/Sdk"
cd /c/dev/claude_code/biblemem
bash scripts/build-apks.sh          # 두 판 → 산출물APK/
```
`android/local.properties`(SDK 자리)는 Android Studio 로 `android/` 를 한 번 열면 저절로 생긴다.
웹으로 보기는 `npx serve -l 8080 .` (또는 `.claude/launch.json` 의 bible-static-server).

## 7. Claude Code 에서 잇기

1. Claude Code 를 `C:\dev\claude_code\biblemem` 에서 연다
2. 첫 말: **「`…\항상예수께로_윈도우이전\2_클로드_메모리` 의 파일들을 이 프로젝트 메모리로 옮겨 줘. 그리고 docs/작업기록-2026-10-05~06.md 와 docs/윈도우로-옮기기.md 를 읽어 줘.」**
   — 메모리 폴더 자리(`%USERPROFILE%\.claude\projects\<경로>\memory\`)는 경로마다 이름이 달라, Claude 가 직접 옮기는 편이 확실하다
3. 전역 설정(`4_전역설정/`)은 `%USERPROFILE%\.claude\` 에 같은 이름으로 둔다(rules · agents · commands · skills · hooks · AGENTS.md).
   `settings.json` 은 플러그인 목록뿐이라 그대로 두면 Claude Code 가 플러그인을 다시 받는다.
   **훅(hooks)은 맥에서 쓰던 명령이 들어 있을 수 있다** — 이상하면 Claude 에게 윈도우에 맞게 고쳐 달라고 한다

- 에뮬레이터 시험(`pharmacare_tablet`)은 맥에 있다 — 윈도우에서는 Android Studio 의 Device Manager 로 새로 만든다
