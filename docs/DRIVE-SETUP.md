# 구글드라이브 첨부 복사 — 최초 1회 설정

첨부파일(사진·문서 등)은 기본적으로 이 기기(IndexedDB)에 저장됩니다.
구글드라이브 복사를 켜면 허브 ⚙ 설정의 "☁️ 지금 복사"로 지정 폴더에 사본을 남길 수 있습니다.

앱은 `drive.file` 권한만 씁니다 — **이 앱이 만든 파일·폴더에만 접근**하고,
드라이브의 다른 파일은 보지 못합니다.

## 1. OAuth 클라이언트 ID 만들기 (약 5분)

1. https://console.cloud.google.com 접속 → 프로젝트 새로 만들기 (이름 예: `my-daily-bible`)
2. 왼쪽 메뉴 **API 및 서비스 → 라이브러리** → "Google Drive API" 검색 → **사용 설정**
3. **API 및 서비스 → OAuth 동의 화면** → User Type **외부** → 앱 이름·이메일만 입력하고 저장
   - 테스트 사용자에 본인 Gmail 주소 추가
4. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
   - 애플리케이션 유형: **웹 애플리케이션**
   - 승인된 자바스크립트 원본에 앱 주소 추가:
     - `https://<내-넷리파이-주소>.netlify.app`
     - (로컬 테스트용) `http://localhost:8080`
5. 만들어진 **클라이언트 ID** (`xxxx.apps.googleusercontent.com`) 복사

## 2. 앱에서 설정

허브 첫화면 → ⚙ → 클라이언트 ID 붙여넣기 → 저장 폴더 이름 입력(기본 `나의매일성경`) → 저장.
"☁️ 지금 복사"를 누르면 구글 로그인 창이 뜨고, 허용하면 아직 복사되지 않은
첨부 전부가 폴더로 올라갑니다. 복사된 첨부에는 ☁️✓ 표시가 붙습니다.

## 참고

- **APK(WebView)에서는 구글 로그인 팝업이 제한될 수 있습니다** — 그 경우 브라우저(넷리파이 주소)에서 복사를 실행해 주세요. 데이터는 같은 백업 체계로 오갑니다.
- 오프라인에서는 복사가 동작하지 않습니다(첨부 자체는 기기에 안전하게 보관됨).
- 클라이언트 ID는 비밀이 아니며(공개 가능) 이 기기 localStorage에만 저장됩니다.
