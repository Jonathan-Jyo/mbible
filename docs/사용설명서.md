## 1. 홈 (첫 화면)

앱을 열면 **종합달력**이 먼저 보입니다. 다섯 앱의 활동이 날짜마다 색점으로 찍히고, 날짜를 누르면 그날 무엇을 했는지 앱별로 펼쳐집니다. 그 줄을 누르면 해당 앱으로 바로 넘어갑니다.

달력 위에는 이번 달 활동 일수와 연속 기록이 앱별로 놓여 있습니다.

| 자리 | 무엇 |
|---|---|
| 큰 단추 둘 | **📖 성경읽기** · **✦ 성경암송** |
| 작은 단추 셋 | **🙏 매일기도** · **🎵 매일찬양** · **💝 매일나눔** |
| 달력 아래 | **📔 주간 회고** |
| 아래쪽 | **⚙ 설정** · 통합 검색 |

- **통합 검색** — 다섯 앱에 흩어진 글을 한 번에 찾습니다. 해시태그(`#`)도 됩니다.
- **📔 주간 회고** — 안식일 저녁이 되고 이번 주 것을 아직 안 썼으면 *"이번 주를 돌아볼 시간입니다"*가 은은히 붙습니다.
- 달력을 끄면(`⚙ 설정`) 그 자리에 인사말과 «내가 사랑하는 말씀»이 놓입니다.

> **가벼운 판에서는** 기도·나눔·회고 단추가 없고, 달력에도 **성경읽기·성경암송 둘만** 나옵니다.

## 2. 성경읽기

### 상단 메뉴

본문 위, 시스템 정보바 아래에 놓인 단추들입니다.

| 단추 | 하는 일 |
|---|---|
| 🏠 | 첫 화면으로 |
| **성경절** (예: `렘 33:1`) | 성경절 찾아가기. 책 이름을 **쳐서** 찾을 수도 있습니다 |
| **역본 이름** (예: `개역한글`) | 읽을 역본 고르기 |
| **原** | 원어 성경 — 스트롱코드·원전분해·원어사전·원어성구 |
| **註** | 주석 |
| **EGW 로고** | 화잇 저서 서가 — 영한대역으로도 읽습니다 |
| **⇄** | 역본대조 |
| **✦** (오른쪽 끝) | **성경암송 앱으로** 건너가기 |

본문 오른쪽 위에 **`가− 가+`**가 떠 있습니다 — 읽다가 바로 글씨를 2포인트씩
키우고 줄입니다. `⚙ 설정`의 글자 크기와 **같은 값**이라 따로 놀지 않습니다.
화잇 저서 창에도 같은 단추가 있습니다.

**原**·**註**·**EGW 로고**는 **해당 자료를 넣었을 때만** 나타납니다. 자료가 없으면 자리를 차지하지 않습니다.

#### 역본

앱에 담긴 역본은 **개역한글 · NKJV · 화합본(간체) · 일본신개역 · Terjemahan Baru** 다섯입니다.

> 예전 판에는 개역개정·새번역·ESV·화합본(번체)도 목록에 있었습니다. 지금은 **새로 고르는 목록에서는 빠졌지만**, 그때 골라 두셨다면 **역본대조에는 그대로 나옵니다** — 본문 자료가 남아 있어 제대로 읽힙니다.
>
> 역본대조 창을 열면 그 역본들이 **「목록에서 빠진 역본」**이라는 표시와 함께 보입니다. 눌러서 끄시면 됩니다. 좌우보기 세 칸을 그것들이 차지해 다른 역본을 못 고르던 문제도 이것으로 풀립니다.

**베들레헴 성경 앱의 자료(`.bdb`)를 그대로 읽습니다.** 역본·주석·원어·찬미가 악보가 모두 호환됩니다. 넣는 곳은 `⚙ 설정 › 성경 DB 관리`입니다.

#### 원어 성경 (原)

- 스트롱코드가 붙은 원어 본문
- **원전분해** — 낱말의 품사·격·시제
- **원어사전** — 낱말을 누르면 해설
- **원어성구** — 같은 스트롱코드가 쓰인 곳 모두 찾기

원어 해설은 **본문 절 사이에 끼워 보기**와 **새 창으로 보기** 가운데 고를 수 있습니다.

#### 주석 (註)

만나주석 · 화잇주석 · 메튜헨리 · 재림교주석 · 성경관주 · 알게렌스키 등, 넣으신 것이 모두 나옵니다. **절 아래에 끼워 보기**와 **새 창으로 보기**를 고를 수 있습니다.

#### 화잇 저서 찾아가기 (EGW인덱스)

`EGW인덱스.cdb`를 넣으면 절마다 **그 절을 다룬 화잇 저서의 자리**가 붙습니다.

```
소망 44        ← 「시대의 소망」 44쪽
교육 128-9     ← 「교육」 128~129쪽
화잇주석 5권 1116
```

**그 줄을 누르면 본문이 열립니다.** 여는 자리는 이 차례입니다.

| | |
|---|---|
| 1 | 앱에 넣어 둔 **한글** 책 (`ko_소망.wdb` 같은 `.wdb`) |
| 2 | 앱에 넣어 둔 **영문** 책 — 한글본이 없는 책일 때 |
| 3 | **EGW Writings** 홈페이지 — 앱에 그 책이 없을 때 (한글본이 있으면 한글로) |

- 책이 한글·영문 둘 다 있으면 창 위 **한 · 영 · 한영**으로 바꿉니다. 고른 것을 기억합니다
- 아래 **◀ 앞 쪽 · 다음 쪽 ▶**으로 이어 읽고, 가운데 칸에 **쪽 번호를 넣어 바로** 갈 수 있습니다
- 쪽수는 **언제나 영문판 기준**입니다. 한글판은 쪽이 다르게 매겨져 있어도 이 쪽수로 찾습니다
- 한글본에서 어떤 쪽이 따로 나뉘어 있지 않으면 **앞 쪽에 이어져 있다**고 알려 주고 그 자리를 엽니다

책은 `⚙ 설정 › 성경 DB 관리`에서 `.wdb` 파일로 넣습니다. 넣지 않아도 됩니다 —
그때는 홈페이지로 데려다 줍니다.

**서가 — 상단 EGW 로고 칩** — 화잇 저서를 하나라도 넣으면 상단에 EGW Writings 로고 칩이 생깁니다
(`原`·`註`와 같은 규칙 — 안 넣으면 나타나지 않습니다). 누르면 넣어 둔 책이
어느 판을 넣어 두었는지와 함께 늘어서고, 골라서 첫 쪽부터 읽습니다.

    소망      [한 영]      ← 한글본·영문본을 다 넣었다
    각 시대   [한   ]      ← 한글본만
    부조      [   영]      ← 영문본만

**자리를 비워 둡니다.** 「한글·영문·한영」처럼 낱말을 바꿔 채우면 글자 수는
같아도 어느 쪽이 없는지 한눈에 안 들어옵니다. 한 자리는 늘 한글, 한 자리는 늘
영문으로 두고 없는 쪽을 비우면 목록을 세로로 훑어 내려갈 수 있습니다.
`⚙ 설정 › 성경 DB 관리`의 책 이름을 눌러도 같습니다.

**영한대역** — 한 책의 한글본과 영문본을 **둘 다** 넣었으면 창 위에 
**`한 · 영 · 한영`**이 나옵니다. `한영`을 고르면 문단마다 짝을 지어 나란히 놓입니다.

| 화면 | |
|---|---|
| 태블릿 가로 (넓을 때) | **좌우 두 칸** — 왼쪽 한글, 오른쪽 영문 |
| 폰 세로 (좁을 때) | **위아래** — 한글 아래 영문을 옅게. 좌우로 나누면 한 줄에 서너 낱말밖에 안 들어가 읽기가 무너지기 때문입니다 |

두 판은 **같은 쪽번호**(영문판 기준)를 쓰므로 쪽을 넘겨도 나란히 따라옵니다.

> 판마다 시와 성경 인용을 끊는 자리가 달라 문단이 꼭 1:1은 아닙니다. 그런 자리는
> 만들 때 미리 맞춰 두었지만, 한두 문단 어긋나 보일 수 있습니다. **같은 쪽 안에서
> 어긋나는 것이라 눈으로 곧 찾을 거리입니다.**

#### 화잇 저서에도 형광펜

창 위의 **🖍**를 누르면 성경 본문과 똑같이 **낱말 하나하나** 칠합니다. 탭하면
한 낱말, 옆으로 끌면 여러 낱말 — 위아래로 끌면 칠하지 않고 화면이 넘어갑니다.
같은 색을 다시 탭하면 지워집니다. 단추 아래 띠가 지금 든 색이고, 아래 메뉴바의
🟡과 **같은 색을 함께** 씁니다.

**판마다 따로 남습니다.** 한글본에 칠한 것은 한글본에, 영문본에 칠한 것은
영문본에 남습니다 — 영한대역에서는 두 칸에 각각 칠할 수 있습니다. 같은 책이라도
판이 다르면 문단 나눔이 달라, 한데 묶으면 판을 바꿨을 때 색이 엉뚱한 자리로
옮아 가기 때문입니다.

**「전체삭제」**를 누르면 성경에서는 그 장, 저서에서는 **지금 보고 있는 쪽**의
것만 지웁니다.

> 저서의 형광펜은 `📖 성경통독 › 형광펜` 모아보기에는 들어가지 않습니다.
> 그 모아보기는 성경 절을 세는 자리입니다.

> 영문 원판을 못 구한 책(자서전 등)은 쪽번호가 **원판 쪽이 아닙니다.** 화면에
> 「이 판 번호 · 원판 쪽 아님」이라고 밝히고, 인덱스는 그런 책을 앱 안에서 찾지 않고
> 홈페이지로 보냅니다 — 자리가 다르기 때문입니다.

**목차** — 본문 창 위 **목차** 단추를 누르면 장 목록이 뜨고, 장을 고르면 그 자리로
뜁니다. 지금 읽고 있는 장은 금빛으로 짚여 있고, 목록도 그 자리에 맞춰 열립니다.
「시대의 소망」 87장처럼 긴 책도 한 번에 찾아갑니다. 장 구분이 없는 책에는
이 단추가 나오지 않습니다.

> 「화잇주석 7A권」처럼 **성경 순서가 아니라 교리 주제로 엮인 책**은 인덱스가
> 가리키지 못합니다(인덱스는 성경절에서 출발하니까요). 그런 책은 이 길로만
> 읽힙니다.

#### 역본대조 (⇄)

- **끄기 · 상하 · 좌우** 세 가지
- **좌우는 최대 세 역본** (태블릿 가로 화면을 권합니다)
- 맨 위가 **기준 역본**입니다. 지금 읽고 있던 역본이 저절로 기준이 됩니다
- **역본명 표시**를 켜고 끌 수 있습니다

### 하단 메뉴

| 단추 | 하는 일 |
|---|---|
| **◀** **▶** | 이전 장 · 다음 장 (본문을 손가락으로 좌우로 밀어도 됩니다) |
| **🔍** | 성구 검색 — 여러 낱말을 함께(AND), 가까이 있는 것만 찾기 |
| **🟡** | 형광펜 — **낱말 하나하나** 칠합니다. **아이콘 아래 띠가 지금 든 색**입니다 |
| **📋** | 묵상노트 — 절을 고르지 않았으면 화면 맨 위 절에 씁니다 |
| **♪** | **찬미가** — 매일찬양의 `찬미가` 탭으로 건너갑니다 |
| **←** **→** | 이동 경로 되돌아가기 · 앞으로 가기 (앞으로 갈 곳이 있을 때만 나옵니다) |
| **🎙** | 녹음 — 탭하면 이 장 녹음, 길게 누르면 녹음 목록 |
| **📖** | 성경통독 — 진도·형광펜 모아보기·묵상노트 모아보기 |
| **⚙** | 설정 |

**♪**는 찬미가 자료를 넣었을 때만 나타납니다.

#### 형광펜

낱말 단위로 칠합니다. **역본마다 따로** 저장되므로, 역본을 바꿔도 엉뚱한 자리에 색이 남지 않습니다.

`📖 성경통독 › 형광펜` 탭에서 **그은 것을 모아** 볼 수 있고, 본문 검색도 됩니다. **주간 회고**에도 그 주에 그은 밑줄이 모입니다.

#### 묵상노트

절을 고르고 **📋**를 누르면 그 절에 묶인 노트를 씁니다.

| 칸 | |
|---|---|
| **주제** | 예: 위로, 신실 |
| **제목** | 한 줄로 요약 |
| **내용** | `#태그`를 쓰면 홈 통합검색에서 찾힙니다 |

> **장의 끝부분 절에 쓰려면** 그 절을 눌러 고른 뒤 팝업 바의 **📋 묵상기록**을 쓰세요.
> 하단 **📋**는 아무것도 안 고르면 화면 맨 위 절로 가는데, 마지막 절들은 맨 위까지
> 올라오지 못해 그 길로는 닿지 않습니다.

- 날짜는 저절로 남습니다
- **절 사이에 끼워 보기**를 켜면 본문을 읽다가 그 자리에서 다시 읽힙니다
- **📚 모아보기**로 전부 훑고 검색할 수 있습니다
- **주간 회고**에 그 주에 쓴 노트가 모입니다

#### 자동 읽음 표시

한 장에 머물러 **끝까지 내려 읽고 일정 시간이 지나면** 통독 기록이 하나 올라갑니다. 필요한 시간은 그 장의 절 수에 따라 달라집니다.

**같은 장은 하루에 한 번만** 셉니다. 한 구절을 붙들고 오래 묵상해도 횟수가 부풀지 않습니다.

### 절을 고르면 뜨는 바

본문에서 절을 누르면(여러 절은 끌어서) 화면 아래에 **팝업 바**가 뜹니다.

| | |
|---|---|
| **📋 복사** | 글로 복사 |
| **📤 공유** | 다른 앱으로 보내기 |
| **🖼 이미지** | 말씀 카드 그림으로 만들기 |
| **🎙 녹음** | 그 절 낭독 녹음 |
| **🔖 책갈피** | 표시해 두기 |
| **📋 묵상기록** | 고른 절에 묵상노트 쓰기 |
| **★ 기억절** | **성경암송 앱으로 보내기** — 주제를 물어봅니다 |
| **🙏 기도** | **매일기도의 약속말씀으로** 붙이기 |

## 3. 성경암송

기억절을 **다섯 단계로 조금씩 가려 가며** 외우는 앱입니다. 안식일학교 교과의 기억절이 분기·과별로 들어 있고, 내 성경절을 따로 담을 수도 있습니다.

### 다섯 단계

화면을 누르면 다음 단계로 넘어갑니다.

| 단계 | 보이는 것 |
|---|---|
| **1** 전체보기 | 구절 전부 |
| **2** 부분숨김 | 중요한 낱말 몇 개를 가림 |
| **3** 한글자만 | 낱말마다 한 글자만 남김 (한글은 끝 글자, 그 밖은 첫 글자) |

🌅 새벽찬양 · 🙏 기도찬양 · ☀️ 밝은찬양 · 💧 맑은찬양 · 🌙 저녁찬양 · 🌿 천연계

> 여러 곡을 한 번에 들여오는 **🎵 음악 모으기**는 `⚙ 설정`에 있습니다. 처음 한 번 하는 일이라 그리로 옮겼습니다.

### 찬미가

재림찬미가 **가사**와 **악보**를 봅니다. 악보 자료는 베들레헴 성경 앱의 것과 같습니다.

#### 반주 패널

곡을 열면 아래에 얇은 줄이 뜹니다.

```
[반주1 | 반주2 | 찬양]   ▶   🔁   오프라인
```

- **[반주 | 찬양]** — 같은 곡을 여러 출처에서 구했으면 번호가 붙습니다. 어느 것을 듣고 있는지는 펼치면 나옵니다
- **오프라인 / 인터넷** — 지금 음원이 어디서 오는지
- 펼치면 **음정 ▼▲** 과 **박자 ◀▶**

**음정**은 실시간 변환이 아니라 **그 음정으로 미리 만들어 둔 파일**로 갈아 끼우는 방식입니다. 그래서 가진 파일이 있는 만큼만 눌립니다 — 없으면 잠깁니다. **박자**는 파일 없이도 늘 조절됩니다(속도만 바뀌고 음은 그대로).

악보를 볼 때 패널이 가리는 만큼 **악보가 더 올라갑니다.**

#### 음원 넣기

`⚙ 설정 › 📁 찬미가 음원 폴더`에서 폴더를 한 번 고릅니다. **복사하지 않고 그 폴더에서 바로 읽습니다.**

```
아무이름폴더/
├ 연합회/      ├ 반주/   001.mp3 · 001_pitch_1_tempo_0_pitched.mp3 …
│              └ 찬양/   001.mp3 …
└ SDApraise/   └ 찬양/   444.mp3 …
```

- **폴더 이름은 무엇이든** 좋습니다. 고르신 폴더가 곧 뿌리입니다
- 파일 이름은 **숫자만 맞으면** 됩니다 — `444.mp3`, `001.mp3`, `444 주 예수.mp3`
- 출처별로 칸을 나누면 섞이지 않습니다
- **기기 안의 폴더**를 고르세요. 구글 드라이브는 목록을 다 못 읽고 인터넷 없이는 재생되지 않습니다

## 7. 주간회고

한 주를 돌아보며 쓰는 곳입니다. 홈의 **📔 주간 회고**로 들어갑니다.

## 8. 두 판의 차이 · 자료 옮기기

### 두 판

| | 항상예수께로 **Salt** | 항상예수께로 **light** |

`⚙ 설정 › 데이터 백업`에서 `.zip` 하나로 담고 풉니다. 기기를 바꾸실 때 이 파일만 옮기시면 됩니다.

- **음원(mp3)은 기본으로 빠집니다** — 수백 MB가 될 수 있어서입니다. 넣으려면 따로 켜세요
- 푸실 때 **합치기**와 **덮어쓰기**를 고를 수 있습니다

### 성경·주석 자료 넣기

`⚙ 설정 › 성경 DB 관리`에서 **베들레헴 성경 앱의 자료**를 그대로 넣습니다.

| 확장자 | |
|---|---|
| `.bdb` | 성경 역본 |
| `.cmt` | 주석 |
| `.sdb` `.dct` | 원어·사전 |
| `.hdb` | 찬미가 가사 |

### 찬미가 음원을 SD카드에 둘 때

7~8GB가 되므로 SD카드가 편합니다.

- 카드 형식은 **exFAT**이어야 합니다. 맥이 기본으로 쓰는 APFS·Mac OS 확장은 안드로이드가 못 읽습니다
- **맥에서 복사하셨다면** 맥이 남긴 숨김 파일을 지우고 빼세요. 파일마다 `._`로 시작하는 짝이 생기는데, 안드로이드에는 깨진 파일로 보입니다

```bash
V=/Volumes/카드이름
find "$V" -name '._*' -delete
find "$V" -name '.DS_Store' -delete
rm -rf "$V/.Spotlight-V100" "$V/.fseventsd" "$V/.Trashes"
touch "$V/.metadata_never_index"
```

- 뺄 때는 반드시 **안전하게 꺼내기**를 하세요. exFAT은 큰 파일을 많이 쓴 직후에 예민합니다
