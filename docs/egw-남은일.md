## 1. 표지에 코드가 없어 건너뛴 책 셋 (2026-08-19 미룸)

책 목록에서 코드를 알아낼 때, **표지 쪽에 `data-refcode` 가 없는 책**은
코드가 빈칸으로 기록되고 수확 대상에서 빠졌다.

| 책번호 | 책 | 인덱스가 부르나 |
|---|---|---|
| 11338 | 그리스도인의 마음과 품성과 인격 **1** | 아니오 (약호표에 `MCP` 없음) |
| 11298 | 생애의 빛 | 아니오 |
| 11329 | 문서전도봉사 | **확인 필요** — 약호표의 `문전`(`CM`, 317줄)일 수 있다 |

2권(`13854`)은 표지에 코드가 있어 `2MCP` 로 잘 받혔다. 1권만 빠진 까닭이 이것이다.

**고친 것은 이미 들어가 있다** — `egw_fetch.py` 의 `probe()` 가 표지에서 코드를
못 읽으면 `Next` 로 한 걸음 더 들어가 읽는다. 다만 `booknr.json` 에 *빈 코드로*
이미 기록돼 있어 다시 읽지 않는다(확인한 책은 건너뛰므로).

**할 일**: `Gospel_Harmony/EGW/raw/booknr.json` 에서 위 셋의 항목을 지우고
`--probe` 를 다시 돌린다. 요청 세 번이면 끝난다.

우선순위 낮음 — 셋 다 성경절에서 출발해 찾아갈 일이 없고, 서가에서 직접 펴서
읽을 때만 쓰인다. 다만 `문서전도봉사`가 `CM` 이면 인덱스가 부르므로 그때는
값이 올라간다.
