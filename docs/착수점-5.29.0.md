## 3. 할 일 (차례대로)

### ① 첫화면 (index.html)
- 윗줄 순서를 성경읽기 · **말씀듣기** · 성경암송 으로. 말씀듣기를 **늘 보이게**(지금 `hidden` + 앱에서만 푸는 코드 → 빼고 `.hub-actions` 를 늘 3칸)
- 360·320px 폭에서 넘침 없는지(디자인 노트 26)

### ② 말씀듣기 화면 (listen.html · js/listen-app.js)
- 위쪽 칸 셋 → **아래 메뉴줄 넷**: 📖 성경듣기 · 🎙 예언의신듣기 · 📻 설교듣기 · ⚙ 설정 (다른 미니앱의 `.tabbar` 모양 — praise.html 참고)
- 재생 막대는 메뉴줄 위에 뜬다(praise 의 `#player` 자리 계산 참고)
- 강조색 `--listen` 을 라벤더로, 「들음」은 초록 대신 라벤더 채움 + ✓ (노트 05)
- ⚙ 설정: 폴더 위치(③과 이어짐) · 기본 빠르기 · 건너뛰기 15/30초 · 들은 기록 지우기
- 성경듣기 장 칸에 성경읽기 「읽음」 작은 점(통독 기록 `isChapterRead` 와 같은 저장소를 **읽기만**)
- 브라우저: 화면은 열리고 「안드로이드 앱에서 됩니다」

### ③ tojesus 자동 찾기 (안드로이드 · 11항)
- `AndroidManifest.xml`: `MANAGE_EXTERNAL_STORAGE`(11+), `READ_EXTERNAL_STORAGE`(≤10, `maxSdkVersion 32`), `requestLegacyExternalStorage="true"`(10)
- `TojesusFolderPlugin`: `allFilesStatus()` · `requestAllFiles()`(설정 창 `ACTION_MANAGE_APP_ALL_FILES_ACCESS_PERMISSION`) ·
  `findDefault()` — `StorageManager.getStorageVolumes()` 의 각 뿌리에서 `tojesus` 찾기(내장 먼저)
- **연결 정보 하나로**: `{ way: "auto", path }` 또는 `{ way: "picked", tree, root }`. 고른 것(picked)이 있으면 먼저
- 파일 길(java.io.File)과 SAF 길을 한 부품 안에서 고른다 — `scan` · `openRead/readNext` · `ensureDirs` · `zipList/zipExtract` · `deleteDoc` 모두
- `TojesusMedia.serve` 도 두 길 다(파일 길은 `RandomAccessFile`/`FileChannel` 로 Range)
- `HymnTree.adopt`(찬미가·음악 모으기 칸)는 SAF 전용이다 → 자동(파일 길)일 때는 HymnTree 에 「파일 길 뿌리」를 넘기는 방법을 정해야 한다 — **가장 손이 많이 갈 곳**. 길이 안 보이면 자동일 때도 찬미가는 SAF 로 한 번 고르게 두고 대표에게 알린다
- 첫화면 ⚙ 파일관리 카드(js/tojesus-folder.js): 처음이면 「모든 파일 접근 허락 → 자동으로 찾기」를 먼저, 거절하면 지금처럼 폴더 고르기. 「다른 폴더 고르기」 단추

### ④ 작은 고침
- 재등록이 tojesus 맨 위의 `00_읽어주세요.md`(안내 파일)를 「구역 밖 파일」로 알리지 않게(맨 위의 `.md`·`.txt`·`tojesus.json` 건너뛰기)
- 백업 범위에 「말씀듣기」 칸 — `js/backup-core.js` SCOPES 에 `bible-listen-` 접두. **지금은 어느 칸에도 없어 백업에서 빠진다(11-22 확인)** — 들은 자리·이어 듣기가 새 기기로 안 옮겨진다

## 4. 빠뜨리기 쉬운 것 (지난번에 실제로 걸린 것)

- 새 화면 파일은 `scripts/sync-www.sh` · `scripts/build-light.sh` 목록에 넣는다(listen.html 이 빠졌었다)
- 앱이 가로채는 주소(`/_tojesus_/`)는 **sw.js 가 건드리지 않게** — 이미 넘기게 돼 있다. 새 주소를 만들면 같이
- 바뀐 JS·CSS 는 html 의 `?v=` 를 올리고 `sw.js` 의 `APP_VER` 도 올린다
- 커밋·푸시는 **빌드할 때 한 번에**. 푸시 전 `gh auth switch --user Jonathan-Jyo`, 끝나면 `Jotimjang`
- `.claude/launch.json` · `Youtube-Download.jpg` 는 이 일과 무관 — 커밋에 넣지 않는다
- 에뮬레이터(`pharmacare_tablet`)는 `-memory 3072` 로, 빌드 뒤 `./gradlew --stop` — 맥 메모리가 모자라면 「응답 없음」이 거듭 뜬다.
  CDP 로 들여다보는 동안 confirm/alert 가 떠 있으면 호출이 멈춘다 — 그때는 adb 캡처로만
- 에뮬레이터를 끄고 켜면 앱 안 저장소(IndexedDB)가 비는 일이 있었다 — 재등록이 다시 들이게 5.28.0 에서 고침
